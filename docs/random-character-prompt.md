# character プロンプトのランダム分岐

- character の候補をプロンプト関数と参照画像キーのペアの配列で管理する。既存のプロンプトを1つ目、指定された文章を返す関数を2つ目とする。見本画像の仕様は `character-reference-images.md` を参照する。
- 生成ごとに `Math.floor(Math.random() * 配列の長さ)` で1つ選ぶ。2つの候補はそれぞれ50%の確率で選ばれる。
- 2つ目の末尾も入力された性格を使い、画像とスキル名を返すよう指示する。メダル生成とAPIの入出力契約は変更しない。
- OpenAI・R2をモックし、乱数を固定して両方の候補が送信されることを確認する。

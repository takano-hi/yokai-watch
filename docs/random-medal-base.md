# メダルのベース画像を３枚から選択

- `medal.png`・`medal-2.png`・`medal-3.png` を既存の参照画像ディレクトリで管理する。２・３は既存画像のコピーを初期値として配置し、個別に差し替えられるようにする。
- 参照画像キーの配列から `Math.floor(Math.random() * 配列の長さ)` で１つ選ぶ。各候補の確率は1/3で、character の選択とは別の乱数を使う。
- character の生成成功後に選択し、既存の `loadReferenceImage` で選んだ１枚だけを読む。メダル生成には１枚目に生成済みcharacter、２枚目に選択したベース画像を送る。
- 選択したベース画像の読み込み・PNG検証やメダル生成が失敗した場合は、既存どおり `medalFilename: null` でcharacterのみ保存・登録する。別画像への再試行はしない。
- API契約・DB・Web・モック・プロンプトは変更しない。設定や依存パッケージは追加しない。
- OpenAI・R2をモックし、選択境界、送信する画像、各候補の読み込み失敗を確認する。

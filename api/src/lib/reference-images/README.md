# 参照画像

このディレクトリに次のPNGファイルを配置してください。

- `character.png`: character のプロンプト１用の見本画像
- `character-2.png`: character のプロンプト２用の別の見本画像
- `medal.png`: メダルの元画像。生成済み妖怪PNGと一緒に送り、中央に妖怪をはめ込む

パスは `../reference-images.ts` で管理します。環境変数の設定は不要です。
各PNGを差し替えるだけで対応する見本画像を変更できます。
character には1枚目に人物写真、2枚目に選択したプロンプトに対応する見本を渡します。
人物の特徴は写真から、フォルム・絵柄は見本から参照するようAIに指示します。
選択した character の見本が存在しない、読み込めない、またはPNG形式でない場合は、
生成を中止し、OpenAI・R2への送信やDB登録は行いません。
`character-2.png` はプロンプト２用の画像を別途配置してください。
メダルには1枚目に生成済み妖怪、2枚目にこの元画像を渡します。
元画像の枠・背景・装飾を維持するようAIに指示します。
`medal.png`が存在しない、読み込めない、またはPNG形式でない場合は、
メダル生成を行わず、妖怪画像のみを保存し`medalFilename: null`で登録します。

ビルド後も `api/src/lib/reference-images` を配置してください。
APIのDockerfileでは `COPY src ./src` によって画像もコピーされます。
